# Windows用ダウンロード・展開補助の使い方

Windows 10／11の標準PowerShell 5.1を使う補助ファイルです。インターネット接続が必要です。**macOSでは実行できません。** Windows Server 2022・PowerShell 5.1の自動テストで、実際のダウンロード・全ファイルの展開・日本語ファイル名・再実行時の上書き防止を確認しています。生徒さんのWindows 10／11実機での警告画面・会社の制限・Explorer表示は個別確認が必要です。

1. 講義の公開ページから `AI-NORIKO-Windows-Setup.cmd` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックします。
3. 公式講義のGitHub PagesからキットZIPを取得し、SHA-256で配布元の想定値と一致するか確認します。不一致やエラーで停止した場合は、無理に続けないでください。
4. ユーザープロファイル（通常は `C:\Users\ユーザー名`）直下に、短い名前の新しい一意フォルダを作って展開します。既存ファイルは上書きしません。
5. エクスプローラーに表示された `AI-NORIKO-Starter-Kit` フォルダをCodexで選び、講義ページの「P01：共通セットアップ」を貼り付けます。実際の場所は `AI-NORIKO-日時-番号/files/AI-NORIKO-Starter-Kit` です。黒い画面と `NEXT-STEPS.txt` にも保存先が残ります。

この補助ファイルが行うのは、ZIPの取得・照合・展開とフォルダの表示までです。アプリの自動起動、Node.jsやAIモデルの導入、Google連携は行いません。

## 2つ目・3つ目を作る場合（キットv1.2.0以降）

最新版の補助ファイルを再実行すると、毎回別フォルダへ展開されます。キット本体も、開いたフォルダごとに設定・タスク・認証情報・標準ナレッジの保存先を分けます。同じフォルダを開き直すと、その環境の続きになります。

名前や場所を変える場合は**初回起動より前**に済ませてください。導入後の移動・改名は新しい環境として扱われ、古いデータは残りますが自動では引き継がれません。旧v1.1のZIP／補助ファイルは取り直してください。旧版の共有保存先は移行・削除しません。

Googleの同じアカウントや、同じObsidianフォルダを指定すれば、外部の予定・ノートは共通です。お客様用には未設定の配布ZIPと、お客様自身のアカウント・専用ナレッジを使ってください。詳細は[複数導入ガイド](guide/docs/MULTIPLE_INSTALLS.md)をご覧ください。

セキュリティ警告や会社の端末制限で進めない場合は、保護の解除や強行実行をしないでください。公開ページからZIPを手動でダウンロードして展開する方法を使うか、講師へ相談してください。
