MAC / 6 STEPS

Macでインストールする

Mac用を公式からダウンロード ↓

配布元：OpenAI公式。ダウンロードされるのはインストール用の .dmg ファイルです。公式の配布リンク掲載元 ↗

すでにインストールできた方は、手順04「アプリケーション一覧から起動」へ ↓

  1. 01

    Mac用のファイルをダウンロード

    上のボタンを押し、保存が終わるまで待ちます。保存先を選ぶ画面が出たら、まずは「ダウンロード」を選びましょう。

    ここまでできたらOK：ダウンロード完了と表示された。

  2. 02

    Finderの「ダウンロード」から開く

    画面下のDockにある顔の形のFinderアイコンをクリック。左側の「ダウンロード」を選び、今保存した ChatGPT.dmg をダブルクリックします。ファイル名は版によって異なる場合があります。

    見つからないとき：ブラウザのダウンロード一覧で、保存先を表示します。左側に「ダウンロード」がない場合も、ここから探せます。

    ここまでできたらOK：インストール用のウィンドウが開いた。

  3. 03

    アプリを「Applications」にドラッグ

    アプリのアイコンとApplicationsフォルダが表示されたら、アプリのアイコンを押したまま、Applicationsの上へ動かして離します。コピーが終わるまで待ってください。

    Applications ＝ アプリケーション。ここに入れることで、次回からアプリ一覧で開けます。DMGを開いただけでは、まだこのコピーが終わっていません。

    違う形式のインストーラーが開いた場合は、その公式画面の案内に従ってください。「置き換え」と出たら、すでに入っている可能性があるので、先に次の手順で確認します。

    ここまでできたらOK：アプリケーションへのコピーが終わった。

  4. 04

    「アプリケーション」一覧から起動

    Finderの左側にある「アプリケーション」をクリック。ChatGPTを探してダブルクリックします。「Codex」という名前で導入済みの場合は、Codexを開いてください。

    Finder→アプリケーション→ChatGPT／Codex

    一覧が見つからないとき：Finderを手前にして、画面上部の「移動」→「アプリケーション」。または ⇧ Shift ＋ ⌘ Command ＋ A です。

    公式から取得したアプリの初回確認が出たら、アプリ名・内容を確認して開きます。「破損」「開発元を検証できない」などで止まる場合は、下の「困ったとき」へ。保護機能は無効にしません。

    ここまでできたらOK：ダウンロード画面ではなく、アプリのウィンドウが開いた。

  5. 05

    自分のアカウントでログインし、Codexを選ぶ

    アプリのログイン案内から、普段ChatGPTで使っている方法（Google・Apple・メールなど）でログインします。ブラウザが開いたらそこで認証し、完了後にアプリへ戻ります。

    ChatGPTの画面が表示された場合は、ChatGPTの選択メニューから「Codex」を選び、「新しいチャット」などの入力画面を開きます。すでにCodexが表示されていれば、そのままで大丈夫です。

    ログイン中はZoomの画面共有を一時停止。パスワード・確認コードは、講師にも送らないでください。

    ここまでできたらOK：アプリ内でCodexが選ばれ、メッセージ入力欄が見える。

  6. 06

    Dockに残して、次回も迷わず開く

    起動中のアプリアイコンをDockで右クリック（または Control を押しながらクリック）。「オプション」→「Dockに追加」など、Dockに残す項目を選びます。表示名はOSにより異なります。

    まだ作業を始めていなければ、一度アプリを終了し、Finderの「アプリケーション」かDockから開き直せるか確認しましょう。次回はDMGを開き直す必要はありません。

    ここまでできたらOK：次回の起動場所が分かった。

WINDOWS / 6 STEPS

Windowsでインストールする

Windows用を公式からダウンロード ↓

OpenAI公式が案内しているMicrosoft配布のインストーラーです。途中でMicrosoft Storeの画面が出る場合があります。公式の配布リンク掲載元 ↗

すでにインストールできた方は、手順04「スタートメニューのアプリ一覧から起動」へ ↓

  1. 01

    Windows用のファイルをダウンロード

    上のボタンを押して保存を待ちます。これはCodexを使うための公式アプリのインストーラーです。AI NORIKOのZIPや、キット展開用の補助ファイルとは別のものです。

    ここまでできたらOK：公式のインストーラーを保存できた。

  2. 02

    「ダウンロード」フォルダから実行

    画面下のフォルダの形のエクスプローラーをクリックし、左側の「ダウンロード」を開きます。今保存したインストーラーをダブルクリック。ファイル名は時期によって異なるため、今ダウンロードしたものを選んでください。

    見つからないとき：ブラウザのダウンロード一覧から「フォルダーに表示」などを選びます。エクスプローラーは Windows ＋ E でも開けます。

    ここまでできたらOK：アプリのインストール画面が開いた。

  3. 03

    画面の案内に従って、インストールを完了

    公式アプリであることを確認し、「インストール」などのボタンから進みます。Microsoft Store経由の画面が出た場合も、表示された案内に従い、完了まで待ってください。

    管理者の承認が必要になることがあります。会社のパソコンや管理者パスワードが分からない場合は、ここで止めて管理者に確認します。セキュリティ保護の解除や、制限を回避する操作はしません。

    「開く」「起動」などが表示されたら、インストール完了の目印です。ダウンロードしただけでは、まだ完了ではありません。

    ここまでできたらOK：インストール完了を確認できた。

  4. 04

    スタートメニューのアプリ一覧から起動

    画面下のWindowsマーク（スタート）をクリック。「すべてのアプリ」「すべて」などを開き、ChatGPTを選びます。「Codex」という名前で導入済みの場合は、Codexを選びます。

    Windows キーを押して「ChatGPT」と入力しても探せます。見つからなければ「Codex」でも検索。検索結果では、Webサイトではなく「アプリ」と表示される項目を開きます。

    アプリが自動で開いていても、この場所を確認しておくと、次回迷いません。デスクトップにアイコンがなくても、一覧にあれば大丈夫です。

    ここまでできたらOK：スタートメニューからアプリを起動できた。

  5. 05

    自分のアカウントでログインし、Codexを選ぶ

    アプリの案内に沿って、ご本人のChatGPTアカウントでログインします。ブラウザで認証した場合は、完了後にアプリへ戻ってください。Microsoft Storeのログインと、ChatGPTのログインは別です。

    ChatGPTの画面が表示された場合は、ChatGPTの選択メニューから「Codex」を選び、「新しいチャット」などの入力画面を開きます。すでにCodexが表示されていれば、そのままで大丈夫です。

    ログイン中はZoomの画面共有を一時停止。パスワード・確認コードは、講師にも送らないでください。

    ここまでできたらOK：アプリ内でCodexが選ばれ、メッセージ入力欄が見える。

  6. 06

    タスクバーに固定して、次回も簡単に開く

    起動中のアプリアイコンを画面下のタスクバーで右クリックし、「タスクバーにピン留めする」を選びます。スタートメニューのアプリを右クリックし、ピン留めできる場合もあります。

    まだ作業を始めていなければ、一度閉じて、スタートメニューやタスクバーから開き直せるか確認しましょう。次回はインストーラーを再実行する必要はありません。

    ここまでできたらOK：次回の起動場所が分かった。

WHEN YOU GET STUCK

ここで止まったら

ダウンロードしたのに、アプリ一覧にありません。

ファイルを保存しただけの可能性があります。Macは手順03の「アプリケーションへコピー」、Windowsは手順03の「インストール完了」まで確認します。「ChatGPT」「Codex」の両方の名前で探してみてください。完了表示があるのに見つからない場合は、むやみに繰り返しインストールせず講師へ相談します。

ブラウザやログイン画面ばかり開きます。

認証にブラウザを使うのは通常の流れです。認証後、MacはDock、Windowsはタスクバーのアプリアイコンに戻ります。「アプリで開く」確認が出たら、公式のログイン操作に続くものか確認して進みます。ログインが完了しない場合は、エラー文を控えて相談してください。

アプリに入れましたが、Codexが見つかりません。

ChatGPTの選択メニューを確認します。公式案内と画面が違う場合は、アプリ名・版・利用アカウント・契約や組織の制限を講師と確認します。アプリの導入とCodexの利用条件は別です。すぐに追加契約やAPIキー作成をする必要はありません。

「このPCでは使えない」「管理者が必要」「保護されています」と出ます。

エラーを読まずに進めないでください。対応OS・端末条件は公式の最新案内を確認します。会社の制限は管理者へ。セキュリティソフトの停止、OSの保護解除、コマンドでの強行インストールはこの講義では行いません。

Macの画面に、インストール用の白いディスクが残っています。

DMGを開くと、インストール用ディスクが表示されることがあります。アプリケーションへのコピーが終わり、そこから起動できることを確認したら、インストール用ウィンドウを閉じてディスクを取り出せます。使用中と出たら強制的に取り出さず、講師へ確認してください。アプリ本体をゴミ箱へ移さないようにしましょう。

講師に伝えるときは、この3つ

① MacかWindowsか　② 何番の手順か　③ 表示されたメッセージ

スクリーンショットは、メールアドレス・パスワード・認証コードを隠してから送ってください。
