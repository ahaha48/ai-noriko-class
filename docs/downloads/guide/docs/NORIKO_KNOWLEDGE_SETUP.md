# NORIKOナレッジ（のりこ思考パック）の導入

更新日：2026年9月18日／Mac・Windows共通

## まず「誰の知識か」を分けます

| 種類 | 中身 | 入れ方 |
| --- | --- | --- |
| 自分のナレッジ | 自分が確認した考え方・記録・判断基準 | 共通ガイドSTEP 5、P04・P05・P10 |
| NORIKOナレッジ | 石橋のりこのインタビューを編集した参照教材＋構造化思考の補助教材 | このページとP21。主催者から受け取る別パック |

アプリ名やキャラクターが「NORIKO」でも、思考ノートが自動で入るわけではありません。講師の私的なObsidianやChatGPT全履歴をコピーするものでもありません。

対象は **AI-NORIKO-Character-Thought-Pack_v1.1.0_20260911.zip**。12テーマ＋案内のMarkdown 13件と、開口・閉口の画像2枚が入っています。構造化思考は「目的→事実→課題→選択肢→判断基準→次の行動」を整理するAI作成の補助教材で、講師の過去の独自メソッド・直接発言として扱いません。

### 提供前に主催者が確認すること

現パックは **「配布前の本人確認用・先行版」** です。受講者への提供可否・提供範囲は主催者が確認します。価格、利用人数、サポート、改変・再配布・商用利用の範囲はパックで確定していません。この導入手順は許諾や販売権を新たに与えるものではありません。主催者から案内がない場合は、先に確認してください。

パックは本体・資料ZIPとは別です。このガイドに手順があっても、パックの購入・提供・導入が自動で済むわけではありません。

## STEP 1 本体でサンプル相談まで完了する

[共通導入ガイド](COURSE_GUIDE.md)のSTEP 1〜5を先に進めます。必要なものは、起動できるAI NORIKO、相談できる会話AI、設定済みのナレッジフォルダです。Google・Fish Audio・売上連携は不要です。

最初の確認はローカルAIで、音声をオフにして行えます。パックのコピー処理自体にAPI呼び出しはありません。会話サービスや音声の費用・送信先は各自の設定によります。

## STEP 2 3つのフォルダを確認する

1. パックZIPを展開します。Macはダブルクリック、Windowsは右クリック→「すべて展開」。ZIPの中から実行しません。
2. 展開後のパック内に `README.md`、`manifest.json`、`knowledge`、`assets`、`scripts` が見えるか確認します。
3. **本体フォルダ**は `AI-NORIKO-Starter-Kit` です。`package.json` と `START_HERE.md` がある方をCodexで開きます。資料専用のLearning-Guideではありません。
4. NORIKOの設定→「Obsidianナレッジ」で、**現在設定しているナレッジフォルダ**を確認します。Mac・Windowsとも標準はDocuments（書類／ドキュメント）内の `AI-NORIKO-Knowledge`。OneDrive等で場所が異なる場合もあるため、画面の実際の保存先を優先します。
5. Obsidianで「フォルダを保管庫として開く」を選び、同じナレッジフォルダを開きます。Obsidianアプリ本体の場所、キット、パックの展開先は選びません。

本体・パック・ナレッジは別フォルダのままにします。認証情報や私的ノートを配布フォルダへ移さないでください。

## STEP 3 内容とコピー先を確認して追加する

おすすめは、[P21](PROMPTS.md#p21-norikoナレッジの追加)を**本体フォルダを開いたCodex**へ貼る方法です。パックとナレッジの場所を伝え、表示されたコピー先を確認してから実行を承認します。キーやパスワードは不要です。

### ノートだけ手動で入れる場合

1. 残したい相談を先に保存し、NORIKOを終了します。
2. 設定済みナレッジ内に `NORIKO-Thought-Pack-v1.1` フォルダを作ります。同名フォルダがある場合は重ねてコピーせず、既存内容を確認します。
3. パックの `knowledge` 内にある **13個の `.md` だけ**をコピーします。README、プロンプト、スクリプト、画像をナレッジへ丸ごと入れません。
4. 自分の記録は別フォルダのままにします。パック原文を自分の方針に書き換えず、「参考にした点」「自分との違い」を自分用ノートへ記録します。
5. NORIKOを再度起動します。ノートだけの追加ならアプリの再ビルドは不要です。

### スクリプトを使う場合

パックのフォルダで実行します。次の `<設定済みナレッジフォルダ>` は実際の場所へ置き換え、引用符は残します。Node.jsが必要です。Mac・Windows共通です。

```text
node scripts/install.mjs --knowledge "<設定済みナレッジフォルダ>"
```

これはプレビューだけです。`knowledgeDestination` が確認した場所であること、13件を追加することを確認し、承認後に実行します。

```text
node scripts/install.mjs --knowledge "<設定済みナレッジフォルダ>" --apply
```

同じ内容が導入済みなら重複追加しません。既存ノートが変更されている場合は上書きせず停止します。エラーを無理に回避しないでください。

### v1.0が入っている場合

旧 `NORIKO-Thought-Pack-v1` を見つけたら、追加前に止まります。本人の追記を確認し、本人が選んだ**検索対象の外側**へ旧フォルダをバックアップしてからv1.1を追加します。保管庫内に「backup」を作るだけでは検索対象から外れません。削除や上書きは不要です。新旧を同時に置くと重複参照の原因になります。

### キャラクターも変更したい場合だけ

現在のキットにも同じキャラクターがあるため、ノート追加だけで構いません。別キャラクターから差し替える場合は、元画像をバックアップし、パック内START_HEREの手順を使います。スクリプトに `--kit "<本体フォルダ>"` を付けたプレビューを確認してから実行し、本体側で `npm run check`、`npm run build`、再起動を行います。本人の名前・Google・音声・保存先設定は変更しません。パックには講師本人の音声・Fish AudioボイスIDは含まれません。

## STEP 4 「入った」と「回答で使えた」を別々に確認する

1. Obsidianで `NORIKO-Thought-Pack-v1.1` を開き、13件あるか確認します。
2. `04_無料対応と追加料金.md` と `12_構造化思考.md` を開き、文章が読めることを確認します。
3. NORIKOの設定→「Obsidianナレッジ」で接続状態を再確認します。追加前と比べて13件増えているか確認します（初めて追加した場合）。検索テストも実施します。
4. NORIKOへ次を貼ります。

```text
相談です。石橋のりこの思考パックを参考資料として使ってください。私は講師本人ではありません。
お客様から追加デザイン10枚を無料で頼まれています。作業は3時間かかりそうです。
資料の判断基準、今回の対応案、確認すべきことを分け、参照したノート名を教えてください。
資料が見つからなければ不明と答えてください。金額の例を現在の料金表として断定しないでください。
```

5. `04_無料対応と追加料金.md` が参照に含まれるか、大量の無償対応を当然とせず工数と契約範囲を確認する回答か、元ノートと比較します。もっともらしい回答だけでは合格にしません。
6. 続けて「今回は1時間以内でできる作業だけならどうしますか？」と聞き、変更した条件を踏まえているか確認します。
7. 次は新しい相談として「構造化思考のノートを参考に、勉強会の企画を目的・事実・課題・選択肢・判断基準・次の行動に整理したい」と聞き、ノート12の参照を確認します。

完了条件は **13ノートの配置・検索・根拠付き相談** の3つです。追加しただけで、毎回全ノートを読み込んだり、講師本人を完全に再現したりするわけではありません。AIの回答は本人の発言・正式な承認ではありません。読み上げやGPT-Live等、別の会話経路へ自動で適用されたとみなさず、使う経路ごとに参照を確認します。

## STEP 5 自分の記録を増やす

講師の考えを参考にしたあと、自分が採用する方針は別ノートにします。「石橋のりこの資料」「自分の確定方針」「AIの提案」を混ぜません。自分の考えと違う場合は、自分の判断として違いを記録します。

NORIKOでの記録は、保存先と下書きを確認してから保存します。会話画面に表示されただけではObsidianへの保存は完了していません。実際のMarkdownファイルをObsidianで開いて確認してください。

## 困ったとき・元に戻す

- **件数が増えない**：現在の設定先とコピー先、拡張子 `.md`、ZIP展開済みかを確認。別の保管庫を見ていないか確認します。
- **関係のない回答**：質問に「無料対応」「追加料金」「構造化思考」など具体的なテーマを入れます。参照ノートと回答を比較し、出典をAIが作っていないか確認します。
- **講師本人と呼ばれる**：「私は講師本人ではありません」と伝えます。ノート内の人物と利用者を区別します。
- **導入スクリプトが停止**：既存版や変更済みノートを上書きしないための保護かもしれません。エラーをCodexへ伝え、勝手に既存フォルダを削除しません。
- **戻したい**：NORIKOを終了し、追加した `NORIKO-Thought-Pack-v1.1` だけを検索対象の外へ移します。自分のノートや認証は触りません。画像も変えた場合だけ元画像を戻し、ビルド・再起動します。
