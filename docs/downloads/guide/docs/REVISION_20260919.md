## 別フォルダを別環境として扱います

本体の実フォルダパスから環境IDを作り、設定・認証等の保存先と、標準ナレッジ・AI作業先を環境ごとに分けます。同じフォルダから再起動すると、その環境の保存内容を引き続き使います。

最新版ZIPを別フォルダへ展開すれば、個人用AI NORIKOを残したまま練習用等を導入できます。ただし本体フォルダを後から名前変更・移動すると別環境になります。元データを自動削除せず、旧v1.1の共有プロフィールも自動取り込みしません。
