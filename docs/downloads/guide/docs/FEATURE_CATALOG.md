# 機能一覧と実装状況

2026-09-18の配布ソースに基づきます。「実装あり」は各PC・アカウントでの動作保証ではありません。Windows実機・実アカウント・実会話モデルの未確認項目は導入時に別途確認します。

| 内容 | 区分 | 必要な準備・範囲 |
| --- | --- | --- |
| 起動、名前、手動タスク、音量・ミュート | 基本機能 | Node.js、初回設定 |
| 自由なテキスト相談 | 連携後に利用 | Ollamaとモデル、または本人が選ぶ会話API |
| 相談モード・追加質問 | 基本UI＋会話AI | 直近12メッセージ・文字数上限あり。起動中のみ、新しい相談で区切る |
| Obsidianの関連ノート参照 | 連携後に利用 | フォルダ指定、Markdown、会話AI。local/API共通で上位5件の抜粋、外部APIでは送信内容を確認 |
| Obsidianへの確認付き記録 | 設定後に利用 | タイトル・本人発言・AI提案を確認・編集後に新規Markdown保存。既存ノートは上書きしない |
| NORIKO思考パックの追加 | 任意の別教材 | 主催者の提供条件を確認後、P21と専用手順で13ノート追加・参照試験。本人の完全再現ではない |
| 本人の判断基準で壁打ち | 活用方法 | 本人確認済みノート。完全再現は保証しない |
| 社長の方針を参照する練習 | 活用方法・単独試作 | 架空／承認済みサンプルで責任者が検証 |
| Google Calendar閲覧、Tasks登録・完了 | 連携後に利用 | 各自のOAuth・許可 |
| 毎朝の予定・タスク報告 | 設定・連携後 | 指定時刻にアプリが動作している必要あり |
| 端末読み上げ | 端末依存 | 本人のクローン声とは別 |
| Fish Audioで本人の声 | 連携後に利用 | 本人のキー・ボイス。本文を外部送信 |
| 音声入力 | 連携後に利用 | マイク権限とWhisper等の認識環境 |
| ニュース・天気・公開ライブ | ネット接続後に利用 | 配信元・地域・終了状況により利用可否が変わる |
| Codex／Claude CodeへのAI作業依頼・引き継ぎ | 確認・連携後に利用 | 実行先・依頼本文・会話を確認して承認後開始。CLIの導入・ログイン・利用枠はアプリ版と別確認 |
| 登録済みプロジェクトを開く | 設定後に利用 | 本人登録フォルダと対応アプリ |
| 売上CSV・手入力・報告 | 任意の既存機能 | 初期非表示。必要な人だけ有効化 |
| 複数AIプロジェクト統合モニター | 追加開発 | 更新時刻だけで完了と断定しない |
| 1日1ファイルへの追記・専用記録ボタン | 必要なら追加開発 | 現状の保存形式を確認して設計 |
| 社員ログイン、会社・部署別権限 | 企業運用前の追加開発 | ローカル1人用キットには未実装 |
| 社長への送信・承認履歴 | 追加開発 | 文案と実送信を区別。決裁は本人 |
| 根拠資料・日付・版の監査可能な表示 | 企業運用前の整備 | 現状の参照表示だけで企業品質を保証しない |
| 社員共有画面・サーバ・継続監視 | 追加開発・運用設計 | 個人PCや保管庫の公開で代用しない |
| 配布用常駐アプリ・自動起動 | 別途導入支援 | OS別の署名・起動・更新・設定保持の検証 |

## 追加依頼の順番

P12で目的、誰が使うか、入力、出力、禁止操作、受け入れテストを明確にします。Codexが既存設定で足りるか、開発が必要かを確認します。見積り・外部送信・権限変更の説明後、本人が承認して実装します。

実装後は動作確認、再起動、設定保持、既存機能への影響、説明書の更新を確認します。試験できなかったOSや連携は未確認と記録します。
