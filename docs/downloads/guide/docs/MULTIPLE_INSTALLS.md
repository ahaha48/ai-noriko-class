# 自分用を残して、練習用・別用途をもう1つ作る

更新日：2026年9月19日／本体v1.2.0以降

**最新版の未使用ZIPを別のフォルダに展開すると、別のAI NORIKOとして導入できます。** 今使っている個人用AI NORIKOを消す必要はありません。

## 仕組みを一言で

「本体フォルダの場所」が、それぞれのNORIKOの目印になります。表示する秘書名ではありません。

| 操作 | どうなる？ |
| --- | --- |
| 同じ本体フォルダから終了・再起動 | その環境で保存した設定・タスク等を継続 |
| ZIPを別フォルダへ展開して初回起動 | 設定・ナレッジ・作業先が別の新しい環境 |
| 展開後の名前が `AI-NORIKO-Starter-Kit (1)` | 元と別の場所なので独立した環境 |
| 本体フォルダを後から移動・名前変更 | 場所が変わるため別環境として起動 |
| ショートカットなどから同じ実フォルダを開く | 別環境にはならず、同じ環境 |

「名前変更」は**本体フォルダ名**のことです。NORIKOの設定画面で秘書名を変える操作は環境の切り替えではありません。

## もう1つ導入する手順

1. 最新の未使用 `AI-NORIKO-Starter-Kit.zip` を用意します。設定済みの自分用フォルダを配布用に流用しません。
2. MacはZIPを展開、Windowsは右クリック→「すべて展開」。今使っている本体とは別の場所を選び、既存ファイルを上書きしません。
3. 分かりやすい本体フォルダ名・保管場所を**初回起動前に**決めます。例：自分用と練習用。それぞれに `package.json` と `START_HERE.md` があることを確認します。
4. Codexで今回の本体フォルダだけを開き、P01を送ります。診断で本体の実フォルダと環境IDを確認します。起動後は設定の「このAI NORIKOの保存先」で「本体フォルダ」「環境ID」「設定・タスク・認証」「標準ナレッジ」「AI作業の保存先」が既存環境と異なることを確認します。本人データやキーの中身を開く必要はありません。
5. 新しいNORIKOを起動し、初回設定を行います。架空の練習タスクを追加して再起動し、同じ環境では保存が残ることを確認します。
6. Obsidianは**新しいNORIKOの設定に表示されたフォルダ**を開きます。思考パックを使う場合も、P21のコピー先を今回の環境で確認します。
7. Google・音声・会話API等は必要なものだけ、その環境の利用者本人が接続します。キーや認証情報を他の環境から勝手にコピーしません。

## 保存場所はどこ？

`<環境ID>` は本体の実フォルダパスから自動で作られる20文字の識別子です。自分で入力・作成する必要はありません。

| 内容 | 標準の保存場所 |
| --- | --- |
| アプリ設定・認証等のユーザーデータ | OSのappData / `AI NORIKO Starter/instances/<環境ID>` |
| Markdownナレッジ | Documents / `AI-NORIKO-Instances/<環境ID>/Knowledge` |
| 明示的に依頼したAI作業 | Documents / `AI-NORIKO-Instances/<環境ID>/Workspaces` |

MacのappDataは通常 `Library/Application Support`、Windowsは通常 `%APPDATA%` です。Documentsは「書類」「ドキュメント」等で表示され、OneDrive等の設定で場所が異なる場合もあります。推測したパスではなく、診断やNORIKO設定の実際の場所を確認します。

技術上は、本体のcanonical（リンク等を解決した）実フォルダパスのSHA-256先頭20文字を `instanceId` に使います。これは保存先の取り違えを避けるための識別子で、アクセス権を作る仕組みではありません。

## フォルダを移したら初期画面になった

元の設定やノートが自動削除されたわけではありません。新しい場所なので別環境として起動しています。アプリを終了し、本体を以前と同じ実フォルダの場所へ戻すと、元の環境を再び使えます。

移動先へデータを引き継ぎたい場合は、**移行する前に講師へ確認**してください。対象環境、必要なノート、外部接続、バックアップ、戻し方を確認します。暗号化された認証ファイルや既存データを手作業で丸ごと移す方法は勧めません。元の保存フォルダを削除して解決しようとしないでください。

## v1.1以前から更新する場合

旧版の共有プロフィールは自動で取り込みません。v1.2の環境は新しい初期設定から始めます。旧版の保存先や `AI-NORIKO-Knowledge`・`AI-NORIKO-Workspaces` はそのまま残り、勝手に移動・削除しません。

以前の情報を使いたい場合は、利用者本人が引き継ぐ範囲を決めて講師へ相談します。講師の個人用AI NORIKO本体・認証・保管庫も、このキットの導入で変更しません。

## 顧客へ導入するときの注意

- 配るのは最新版の未使用ZIPです。自分の実データが入ったフォルダ、ナレッジ、作業成果、キー、認証ファイルは配りません。
- 顧客本人のPC・アカウント・許可で設定します。GoogleやAPIキーを講師のものに統一しません。
- 別環境でも、利用者が**同じGoogleアカウントや同じObsidianフォルダを選べば、その外部データは共有**されます。フォルダを分ければ外部アカウントまで自動分離されるわけではありません。
- 同じOSユーザー内の別フォルダは、顧客間の秘密を守る防壁ではありません。実顧客データを1台で扱う場合は、別PC・OSアカウント・アクセス権等を含む運用を別途設計します。
- 社員ログイン、顧客別の権限、共有サーバ、承認機能を追加したわけではありません。会社での共同利用は [企業向けガイド](TEAM_PLAYBOOK.md) の別工程です。

迷ったら、今回起動している本体フォルダと保存先だけを先に確認します。分離確認のために私的ノートや認証の中身を見せる必要はありません。
