# AI NORIKOの名称と設定

講義・配布キットの名称はAI NORIKOです。初期の秘書名はNORIKOで、初回設定から自分の好きな名前にも変更できます。

v1.2以降は本体の実フォルダごとに設定保存先を分けます。同じ本体フォルダから再起動すると、自分で付けた秘書名やその環境の設定を維持します。秘書名の変更と、本体フォルダの名前変更は別です。

旧v1.1の共有プロフィールや講師の個人用アプリの認証・設定は自動取り込みせず、そのまま残します。手動で保存先を削除しないでください。本体フォルダの移動・名前変更、以前のデータの引き継ぎは [別環境の導入](MULTIPLE_INSTALLS.md) を確認します。一部の内部プログラム識別子に旧名が残っていても、表示名を理由に他の環境の設定へ接続しません。

公開する資料や告知ではAI NORIKOの表記を使用してください。
