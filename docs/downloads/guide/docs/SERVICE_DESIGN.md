# 導入支援のサービス設計

## 共通導入と発展を分ける

本教材は「外部講師による導入・活用講座」として使います。講座の受講料・講師への依頼費は教材に掲載せず、主催者が別途案内します。基本導入と発展の説明を扱い、企業用の本番システム開発は含みません。以下の金額は、生徒さんが今後提供するサービスを考えるための仮の価格モデルで、本講座の料金ではありません。

| 提供メニュー | 主な成果物 | 含めない範囲の例 |
| --- | --- | --- |
| 共通の導入支援 | 起動・基本テスト・初回設定・操作説明 | 外部サービス契約費、全機能実装 |
| 個人向け活用支援 | 日々の使い方、本人ナレッジ、選んだ連携 | 無制限の改修、成果保証 |
| 社長ナレッジ整理・試作 | インタビュー、承認済み方針、限定テスト | 社員向け公開、決裁代行 |
| 企業向け追加開発 | 認証・権限・根拠表示・必要な承認導線 | 契約外のシステム、無条件の全社展開 |
| 継続の運用支援 | 方針更新、回答レビュー、障害一次対応 | 24時間対応（別途合意がない場合） |

## 料金を決める前の確認

P19で、対象者、課題、提供範囲、準備物、作業時間、外部費、追加修正、終了条件を決めます。導入支援・追加開発・月次支援を別見積りにします。キットや素材の再配布・商用利用は主催者の条件と各ライセンスを確認します。受講しただけで無条件の再販権が付くとは説明しません。

## 生徒さんのサービス価格モデル

市場相場や正式な販売価格ではなく、提供範囲を考えるための仮定です。金額は税抜の試算用。実際の提示時には税・外部利用料・対応回数・納期・検収条件を明記します。

| サービス例 | 仮の価格 | この例に含める内容 | 別途になるもの |
| --- | ---: | --- | --- |
| 基本導入支援 | 3万円 | 1名・1台、初期設定、起動確認、基本操作、合意した接続1件 | コード変更、大量データ整理、無期限サポート |
| 活用つき導入支援 | 5万円 | 基本導入＋利用場面の設計、サンプル知識の整理、操作練習、質問対応1回 | 独自機能の開発、社員共有 |
| 個別の追加開発 | 10万〜30万円 | 合意した限定機能、設計、実装、テスト、説明書。例：定型レポートや特定プロジェクトの一覧 | 複数システムの大規模連携、企業全体の権限制御、継続保守 |
| 企業向け本格開発 | 50万円〜・個別見積り | 要件に合わせた認証・権限・情報分離・承認・検証の設計と開発 | 無条件の全社展開、無制限の改修、24時間保守 |
| 継続支援 | 月1万〜3万円 | 合意した回数・時間内の更新、利用レビュー、問い合わせ対応 | 大きな追加開発、対応時間外の緊急対応 |

「50万円で企業機能をすべて完成できる」という意味ではありません。人数、部署、扱う情報、連携先、安全性・保守の要件により上振れします。まず要件を整理し、開発する範囲と検収条件を合意します。

追加開発では、実装時間だけでなくヒアリング・設計・テスト・修正・引継ぎの時間も見積もります。導入支援の価格に独自開発を含めず、変更依頼は追加見積りとします。外部講師としての登壇・研修も別メニューにでき、内容・人数・準備量に応じて見積もります。

## 収益ビジョンの計算例

以下は相場・予測・実績ではなく、受注と原価を仮定した教材用の試算です。各自の数字へ置き換えてください。

| 仮の月間プラン | 売上 | 外部直接費 | 自分の工数原価 | 差引の例 |
| --- | ---: | ---: | ---: | ---: |
| 基本導入 30,000円×3件 | 90,000円 | 9,000円 | 12時間×3,000円＝36,000円 | 45,000円 |
| 活用つき導入 50,000円×3件 | 150,000円 | 15,000円 | 21時間×3,000円＝63,000円 | 72,000円 |
| 限定した追加開発 200,000円×1件 | 200,000円 | 20,000円 | 30時間×3,000円＝90,000円 | 90,000円 |

差引＝売上－外部直接費－自分の工数原価。税、広告、営業、固定費を含まないため最終利益ではありません。行は別々の想定で、同時に受注できる保証はありません。追加開発20万円の例は、範囲を絞った機能1件であり、企業向け本格開発を含みません。

例えば追加開発が想定30時間から50時間になると、同じ売上でも差引は9万円から3万円になります。高い価格だけを見るのではなく、実際の作業時間と検収条件を管理することが重要です。

先に小規模な導入実績を作り、実際の作業時間とサポート負荷で価格を見直します。「導入すると必ず稼げる」「社長と同じ判断」は使いません。

## お客様への説明例

共通のAI NORIKOを導入し、ご自身の業務に合わせて使い方を設定します。個人向けは予定や相談、会社向けは社長の判断基準を参照した相談準備を扱います。社員共有は権限設計と検証を経て別途対応します。AIの回答は参考情報で、最終判断は責任者が行います。

## 継続支援のチェック

利用回数、相談準備時間、誤回答、根拠不足、設定トラブル、方針の変更を月次で振り返ります。改善提案を承認してもらってから変更します。必要がない月次契約を必須として販売しません。
