# 困ったときは、止まった段階を確認

エラーを何度も繰り返さず、「今の画面」「やりたいこと」「表示されたエラー」を講師かCodexへ伝えます。キー・メール本文・顧客情報を含む部分は隠します。認証情報を共有チャットへ貼りません。

| 症状 | 確認すること |
| --- | --- |
| 起動しない | ZIPは展開したか／Node.js／npm run doctorの必須項目 |
| フォルダが見つからない | Codexで正しいキットフォルダを開いたか／START_HERE.mdがあるか |
| 無料モードで相談の返事がない | Ollamaが起動中か／モデル名が一致するか／ダウンロード済みか |
| 予定は見えるが自由な相談ができない | 予定取得とAIモデル接続は別。AI設定を確認 |
| Obsidianの内容を使わない | 保存先は同じか／サンプル.mdを保存したか／更新・再読込／質問に関連する記録があるか |
| NORIKOキャラは出るが、のりこの考え方を答えない | 画像と思考ノートは別。P21と専用ガイドで13ノートの配置・検索・参照を確認 |
| 相談が予定確認になった | 「相談です」と伝えるか相談モードへ切り替える。操作したいときは操作モードへ |
| 昔の条件を忘れた | 直近12メッセージ・文字数上限あり。要点を再提示。大事な相談は確認してノート保存 |
| 「記録して」と言ったがファイルがない | 記録確認画面で保存を承認したか／完了に表示された保存先を確認。会話表示だけでは未保存 |
| 存在しない根拠を答える | 採用せず元資料を確認。資料にない場合は不明と答えるルールで再検証 |
| Codex／Claude Codeが未接続 | アプリへのログインとは別に、対象CLIを公式手順で起動・ログイン |
| Googleが未接続 | Calendar／Tasks API、デスクトップ用OAuth、テストユーザー、必要な権限 |
| Google予定が未確認・読み込み失敗 | 古い予定を今日の予定と思い込まない。再接続・再読込後、元カレンダーの日付と比較 |
| 先の予定が見つからない | カレンダー選択・検索期間・予定名の表記・元カレンダー・権限エラーを確認 |
| Fish Audioが別の声 | API接続・声の一覧・選択・保存・試聴の順で確認。サイトログインだけでは未接続 |
| 音声入力できない | マイク許可／FFmpeg・whisper-cli・モデル。まずテキストで試す |
| ライブが止まった | 配信終了・URL変更・埋め込み制限。公開配信の別URLを本人確認後に登録 |
| 声が重なる・Zoomで困る | 読み上げ停止・ミュート・二重起動確認。直らなければ再現手順を記録 |
| PCを再起動したら閉じた | 開発用起動のため。起動ファイルから再開。常駐はP18で別途設計 |

NORIKOナレッジの追加・重複・元に戻す手順は [専用ガイド](NORIKO_KNOWLEDGE_SETUP.md) を確認してください。パック原文を上書きして直そうとしないでください。

## 勝手に有料へ切り替えない

Ollama等の未接続を理由に、外部APIや有料プランへ自動で切り替えません。必要なら料金・送信先・無料案を説明してから本人が選びます。サービスの月額プランとAPI枠は別の場合があります。

## キーが流出した疑いがある

画面共有を止め、サービスの管理画面で本人がキーの失効・再発行を行います。新しいキーはNORIKOの設定欄へ入力します。過去のキーをチャットや資料へ転載しません。

## 会社用で止まった

社員ログイン・権限・承認などは本キットに実装されていません。プロンプトで「社外秘を見せない」と書くだけでは代替できません。[企業向けガイド](TEAM_PLAYBOOK.md) とP16で設計し、権限外の回答や承認済みの誤表示がないか検証してから公開します。

## 確認結果を残す

templates/検証記録テンプレート.mdへ、OS・日時・質問・期待結果・実際の結果・合否・未確認点を記録します。機能追加後は以前できた操作も試し、失敗時はバックアップと変更差分を見て安全に戻します。既存の個人用NORIKOや認証ファイルを消さないでください。
