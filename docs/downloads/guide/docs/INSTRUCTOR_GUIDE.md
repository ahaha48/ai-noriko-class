# 講師用進行資料

更新日：2026年9月18日。「外部講師による導入・活用講座」、初回5名を前提とします。教材に受講料・講師への依頼費は掲載せず、主催者が別途案内します。サービス価格例は生徒さんの事業設計用で、この講座の料金ではありません。企業本番開発や外部利用料は別です。

## 受講前

PCのOS、会社管理の有無、Codex利用可否、Node.js、インストール権限、メモリ・空き容量を確認します。アプリやモデルの大きいダウンロードは事前に案内します。実施時間やサポート期間は主催者が確定します。

Node.jsは24 LTSを推奨（24.14.0で検証、最低22.12.0以上）。本体ZIPと資料ZIPを区別し、本体のpackage.jsonが見える状態まで事前に確認します。Mac・Windowsとも配布ZIPから新規展開→起動→終了→再起動を各端末で確認し、MacでのテストをWindows実機検証の代わりにしません。

配布は最新版のスターターZIP、導入・発展資料ZIP、スライド、プロンプト集を同時に更新します。教材に個人キー・講師の私的履歴がないことを確認します。

NORIKO思考パックを扱う場合は、[専用ガイド](NORIKO_KNOWLEDGE_SETUP.md) とP21を使います。現v1.1.0は本人確認用の先行版のため、編集内容・提供可否・対象者・素材とノートの利用条件を主催者が確認します。本体ZIPや公開配布ページへの無条件同梱はしません。受講者の取り込み先は本人が確認し、講師の私的保管庫・キー・声をコピーしません。

## 進行例（150分の案。開催時間の確定ではありません）

| 時間 | 内容 | 確認 |
| --- | --- | --- |
| 0〜15分 | 共通基盤と2つの発展先 | 企業機能は未実装と説明 |
| 15〜50分 | ZIP、Codex、診断、起動 | 5名の起動状況 |
| 50〜65分 | 初回設定と手動タスク | 追加・完了の最小合格 |
| 65〜95分 | 会話AI・Obsidianサンプル | 自由文、追加質問、参照 |
| 95〜115分 | 個人／企業の相談練習、任意パックの説明 | 送信先と根拠の区別、P21の入口 |
| 115〜135分 | 追加機能とサービス化 | 設定・開発・試算の区別 |
| 135〜150分 | 再起動、振り返り、質問 | 次の本人操作を記録 |

モデルの準備が間に合わない人には操作練習と講師デモを提供し、会話確認は未完了として残します。講師PCの成功を受講者PCの成功とみなしません。

## 5名のチェック項目

参加者ごとに、OS／ZIP展開／Codexでフォルダ読取／診断／起動／手動タスク／会話AI／追加質問／ナレッジ参照／確認付き記録／再起動／次の作業を記録します。任意連携の未設定は失敗扱いにしません。

P06全文で相談が予定確認にならないこと、P11全文で承認前にエージェントが動かないことも確認します。記録は取り消し→未保存、承認→新規ファイルを実際に確認します。思考パック提供対象者は、13件追加・無料対応ノート参照・構造化思考ノート参照の3点を個別チェックします。

ログインやAPIキー操作時は画面共有を止めます。講師がキーを預かる運用にしません。会社向けデモでは架空サンプルだけを使います。

## 伝える順序

共通導入、個人活用、企業の単独試作、追加開発、社員公開前の検証の順です。企業運用の権限・承認機能を、プロンプトを貼れば完成する機能として案内しません。

P番号はWebページ、テキスト資料、スライドで共通です。Codex向けとNORIKO向けを毎回読み上げます。短いスライドの例文は操作の説明で、全文は配布ページまたはPROMPTS.mdからコピーします。

## 配布前・講義後

主催者は開催日、申込先、サポート範囲、利用・再配布条件、料金表示を確認します。講義後は個人7日間の実践か、企業の責任者1人での試作を選んでもらいます。社員公開は別工程です。

既存の個人用AI NORIKO本体、認証情報、Obsidian保管庫はこの教材改訂では変更しません。
