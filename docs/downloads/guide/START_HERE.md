# 最初にここを読んでください — 資料専用

更新日：2026年9月19日／本体v1.2.0対応

この `AI-NORIKO-Learning-Guide` は説明書・プロンプト・記入用テンプレートです。**アプリ本体ではないので、このフォルダではnpmコマンドや起動ファイルを実行しません。**

## アプリを導入したい方

1. 別配布の最新版・未使用 `AI-NORIKO-Starter-Kit.zip` を用意して展開します。既存の本体がある場合は別の場所へ展開し、上書きしません。
2. 展開後の `AI-NORIKO-Starter-Kit` に `package.json`、`START_HERE.md`、`src` があることを確認します。
3. Codexでその**本体フォルダ**を開き、本体のSTART_HEREから進めます。
4. この資料を横に表示し、[共通導入ガイド](docs/COURSE_GUIDE.md) を順番に進めます。

本体v1.2では、実フォルダごとに設定・標準ナレッジ・作業先を分けます。同じ本体フォルダの再起動では保存を維持しますが、移動・名前変更は別環境になります。旧v1.1の共有データや講師個人用アプリは自動移行・削除しません。

思考パックも別教材です。アプリ名・キャラクターだけで講師の考え方が入るわけではありません。主催者の提供条件を確認し、共通導入後にP21へ進みます。

資料のプロンプトは、送る場所を確認して使います。「Codex」向けは本体フォルダを開いたタスクへ、「AI NORIKO」向けは起動済みNORIKOの会話欄へ送ります。APIキー・パスワードは資料やチャットへ貼りません。
