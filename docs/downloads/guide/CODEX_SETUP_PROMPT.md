# 共通セットアップ依頼

この資料専用フォルダでは実行しません。別配布のAI-NORIKO-Starter-Kitを展開し、package.jsonのある本体フォルダをCodexで開いてから、下の依頼文だけを送ります。NORIKOの会話欄にも送りません。

```text
このフォルダのAGENTS.md、START_HERE.md、docs/COURSE_GUIDE.md、docs/FEATURE_CATALOG.mdを読んでください。
docs/MULTIPLE_INSTALLS.mdも読み、本体v1.2.0のフォルダ別環境として導入してください。
まずMacかWindowsか、Node.js、現在のファイルと既存設定を確認してください。Node.jsは24 LTSを推奨、最低22.12.0以上です。資料専用Learning-Guideではなくpackage.jsonのある本体フォルダかも確認してください。
今回の本体の実フォルダと環境IDを確認し、起動後に設定画面「このAI NORIKOの保存先」で設定・ナレッジ・作業先が今回の環境用に分かれていることを確認してください。分離確認だけのために認証や私的ノートの中身を読まないでください。
旧v1.1の共有プロフィール、別環境、講師の個人用AI NORIKOのデータを自動移行・上書き・削除しないでください。移行が必要なら対象・バックアップ・戻し方を説明して私の確認を待ってください。
個人向け・企業向けに共通の基本セットとして、AI NORIKOをセットアップしてください。
npm install、npm run doctor、npm run check、npm run build、npm run smokeを実行し、このフォルダ内で直せる問題を直してください。
売上管理は非表示のままにし、企業の共有・権限・承認機能は未実装と説明してください。
ログイン、課金、権限付与、システム全体へのインストール、フォルダ外の変更は事前に私へ確認してください。
APIキーや認証JSONの中身をチャットへ貼らせないでください。OSの保護を弱めないでください。
最初に起動とサンプル手動タスクの追加・完了を確認してください。

最後に「完了」「未設定の任意機能」「次に本人が操作すること」「再起動方法」を日本語でまとめてください。
NORIKOナレッジを追加したい場合はdocs/NORIKO_KNOWLEDGE_SETUP.mdとP21を案内してください。本人の私的保管庫をコピーせず、提供条件を確認した別パックだけを対象にしてください。
```
