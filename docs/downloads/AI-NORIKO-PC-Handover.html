MAC / WINDOWS

操作と保存場所の目安

以下は標準例です。AI NORIKOの設定「このAI NORIKOの保存先」と、実際に指定したナレッジの場所を優先します。

Macの場合

ZIPはFinderでダブルクリックして展開。コピーは ⌘ C、貼り付けは ⌘ V。Finderの「移動」→「フォルダへ移動」で、確認済みの場所を開けます。

設定など：~/Library/Application Support/AI NORIKO Starter/instances/<環境ID>標準ナレッジ・作業先：書類 / AI-NORIKO-Instances / <環境ID> / Knowledge または Workspaces

「書類」はiCloudなどの設定で場所が異なる場合があります。環境IDを自分で作る必要はありません。

Windowsの場合

ZIPを右クリック →「すべて展開」。ZIPの中を表示しただけの状態では作業しません。コピーは Ctrl C、貼り付けは Ctrl V。エクスプローラーのアドレス欄で確認済みの場所を開けます。

設定など：%APPDATA%\AI NORIKO Starter\instances\<環境ID>標準ナレッジ・作業先：ドキュメント \ AI-NORIKO-Instances \ <環境ID> \ Knowledge または Workspaces

「ドキュメント」はOneDriveなどの設定で場所が異なる場合があります。環境IDを自分で作る必要はありません。

Mac → Windows、Windows → Macでは、ファイルの場所・起動方法・実行環境が変わります。アプリ本体の実行用ファイルや認証ファイルを丸ごとコピーして動く、とは限りません。

認証の保存は止めてください。古い認証ファイルを上書き・削除したり、キーを平文保存したりして解決しようとせず、OSとエラー文を講師へ伝えます。秘密の値や認証ファイルは送らないでください。

原則、自分だけで保管します。ナレッジやローカルデータには個人情報が含まれ得ます。相談時はまずOS、版、状況、秘密を伏せたエラー文だけを送ってください。設定済みの個人バックアップは、配布用スターターキットとして使わないでください。
