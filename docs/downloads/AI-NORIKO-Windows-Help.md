# Windows用ダウンロード・展開補助の使い方

Windows 10／11の標準PowerShell 5.1を使う補助ファイルです。インターネット接続が必要です。**Windows実機では未検証です。macOSでは実行できません。**

1. 講義の公開ページから `AI-NORIKO-Windows-Setup.cmd` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックします。
3. 公式講義のGitHub PagesからキットZIPを取得し、SHA-256で配布元の想定値と一致するか確認します。不一致やエラーで停止した場合は、無理に続けないでください。
4. ユーザープロファイル（通常は `C:\Users\ユーザー名`）直下に、短い名前の新しい一意フォルダを作って展開します。既存ファイルは上書きしません。
5. エクスプローラーに表示された `AI-NORIKO-Starter-Kit` フォルダをCodexで選び、講義ページの「P01：共通セットアップ」を貼り付けます。

この補助ファイルが行うのは、ZIPの取得・照合・展開とフォルダの表示までです。アプリの自動起動、Node.jsやAIモデルの導入、Google連携は行いません。

セキュリティ警告や会社の端末制限で進めない場合は、保護の解除や強行実行をしないでください。公開ページからZIPを手動でダウンロードして展開する方法を使うか、講師へ相談してください。
