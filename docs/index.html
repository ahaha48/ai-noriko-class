WINDOWS / ZIPが開けない方へ

ダブルクリックで、キットを準備。

Windows 10・11向け。ZIPを先に展開する必要はありません。補助ファイルがダウンロードと展開を行い、最後に本体フォルダを開きます。

Windows用 ダウンロード・展開 ↓使い方を保存 ↓
  1. W1
    補助ファイルを保存して、ダブルクリック

    上のボタンから「AI-NORIKO-Windows-Setup.cmd」をダウンロードします。保存したファイルを開くと黒い案内画面が出ます。インターネット接続が必要です。

  2. W2
    「展開が完了しました」を待つ

    配布ZIPの照合後、ユーザーフォルダ内の新しい「AI-NORIKO-日時-番号」フォルダへ展開します。既存のキットや設定は上書きしません。再実行すると別フォルダができます。

  3. W3
    開いた本体フォルダをCodexで選び、P01を送る

    「package.json」と「START_HERE.md」がある「AI-NORIKO-Starter-Kit」が対象です。上の階層やZIPではありません。場所は黒い画面と「NEXT-STEPS.txt」にも残ります。

ここまでで「展開」が完了。初回セットアップはP01へ。

アプリやNode.js・AIモデルは自動で起動・導入しません。Googleや音声の連携も後からです。Macの方は通常のZIPを展開してください。

動作確認の範囲 Windows・PowerShell 5.1の自動テストで、取得・日本語ファイル名の展開・上書き防止を確認済み。各PCの警告画面・会社の制限・フォルダ表示は個別確認が必要です。

03 / SETUP

全員共通の導入手順

Googleや自分の声は後から選べます。順番に、できた状態を確かめます。

  1. 01
    ZIPを展開してCodexで開く

    スターターキットを保存し、ZIPを展開します。デスクトップアプリのCodexで、START_HERE.mdが入ったAI-NORIKO-Starter-Kitフォルダを開きます。

    できた状態：Codexが説明ファイルを読める
  2. 02
    セットアップ文を送る

    下のP01をCodexへ送ります。Node.jsや必須項目を診断します。ログイン、課金、管理者権限は勝手に進めず、講師と確認します。

    できた状態：診断結果と起動方法が表示される
  3. 03
    起動して初回設定

    MacはSTART-MAC.command、WindowsはSTART-WINDOWS.bat。呼び名と秘書名を設定します。初期状態では売上管理は非表示、読み上げ・朝の報告はオフです。

    できた状態：NORIKOの画面が開く
  4. 04
    手動タスクを1件試す

    タスク画面で「練習：説明書を読む」を追加して完了します。Googleをつなぐ前に確認できる、最小の動作テストです。

    できた状態：サンプルの追加・完了ができる
  5. 05
    自由な相談を準備

    P03でOllamaとモデルを確認します。自由な会話には会話AIが必要です。大きなダウンロードや端末への導入は本人の確認後に行います。

    できた状態：自由文と追加質問へ返答が出る
  6. 06
    Obsidianのサンプルを参照

    P04でNORIKOのナレッジ保存先を確認し、Obsidianでも同じフォルダを開きます。架空の判断基準を1件入れ、ノートと回答を比較します。

    できた状態：保存した内容を相談に使える
送る場所の違い

導入・修正・機能追加は「キットを開いたCodex」。日々の相談・記録は「AI NORIKO」。Markdownの確認は「Obsidian」です。NORIKOに相談しただけで、新機能が自動追加されるわけではありません。

04 / PERSONAL

個人のAI秘書として育てる

自分の声は任意です。まず、どんな場面で相談したいかを決めます。

  1. A1
    毎日の場面を1つ選ぶ

    P02で朝の準備、企画の壁打ち、振り返りなどを選びます。音声を止めたい場面も決めます。

  2. A2
    具体的な判断基準を入れる

    P05で一度に1問答えます。「何を、なぜ選ぶか」「例外」を記録し、本人の発言とAIの提案を分けます。

  3. A3
    相談して記録する

    P06をNORIKOに送り、追加質問にも答えます。直近12メッセージを参照します。相談後は「今の相談をObsidianに記録して」。下書きを確認して保存し、Obsidianの実ファイルを確かめます。必要な会話は再起動前に保存します。

  4. A4
    連携と制作を必要な分だけ

    GoogleはP07、本人の声はP08、素材の整理はP09・P10。制作はP11で依頼文を確認し、実行は別途許可します。

05 / TEAM

社長の判断基準を参照するAI相談役

社員が社長へ相談する前に、企画の論点と確認事項を整理する使い方です。本人の完全再現や決裁代行を保証しません。

まずは責任者1人の試作

社員用の認証・権限・承認機能は未実装です。社長の私的履歴や個人アカウントを、そのまま社員へ渡しません。

  1. B1
    対象業務を限定

    P14で「企画の事前チェック」など1つに絞ります。架空のサンプルと別の保管庫で、責任者が検証します。社員招待やネット公開はしません。

  2. B2
    社長が判断基準を確認

    P05と記入テンプレートを使い、方針・理由・例外・出典・日付・版を記録します。承認前の下書きやAIの提案を確定方針へ混ぜません。

  3. B3
    相談準備を練習

    P15で企画を相談します。回答を「資料に基づく内容」「AIの提案」「不足情報」「社長への確認事項」に分けます。

  4. B4
    社員利用の設計・開発

    P16で認証、会社・利用者別の権限、根拠表示、相談履歴、更新管理、外部送信を設計します。フォルダ名やプロンプトだけを権限管理として扱いません。

  5. B5
    公開前に検証

    P17で根拠なし、矛盾、権限外、承認の誤認を試験します。責任者の合格判断後に小規模で開始し、差し戻しや相談準備時間を測ります。

社員に見せる注意書きの例

「社長が確認した資料を参考にしたAIの回答です。社長本人の発言・承認ではありません。」
